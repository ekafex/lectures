# Hyrje ne Laborator


## Plani i Laboratorëve (Java 1–13)

Ky kurs laboratorik synon të prezantojë studentët me të menduarin eksperimental përmes tre fushave kryesore:

- **Matje Fizike**
- **Eksperimente me Kompjuter**
- **Matje me Sensorë**

Fokusi është në **punën praktike**, **mbledhjen e të dhënave** dhe **analizën bazë me Python (Jupyter Notebook)**.



### Java 1 — Mjedisi Conda dhe JupyterLab

**Kategoria:** Kompjuter  
**Objektivi:**  
Instalimi dhe konfigurimi i mjedisit të punës (Conda, JupyterLab). Të mësohet ekzekutimi i kodeve dhe organizimi i një notebook-u.



### Java 2 — Git dhe GitHub

**Kategoria:** Kompjuter  
**Objektivi:**  Kuptimi i bazave të versionimit. Krijimi i një repository, klonimi në kompjuter dhe dorëzimi i punës përmes GitHub Classroom.



### Java 3 — Markdown dhe LaTeX (Shkrim Shkencor)

**Kategoria:** Kompjuter  
**Objektivi:**  Të mësohet struktura e një raporti shkencor me Markdown dhe përdorimi i formulave matematikore me LaTeX.



### Java 4 — Bazat e Python (NumPy & Matplotlib)

**Kategoria:** Kompjuter  
**Objektivi:**  Hyrje në Python për punë shkencore. Krijimi i vektorëve, llogaritje të thjeshta dhe vizualizimi i të dhënave me grafikë.



### Java 5 — Matje Fizike: Gjatësia, Masa, Koha

**Kategoria:** Fizikë  
**Objektivi:**  Matja e madhësive bazë me instrumente laboratorike (vizore, peshore, kronometër). Kryerja e matjeve të përsëritura dhe vlerësimi i pasigurisë.



### Java 6 — Matja e Dendësisë dhe Perhapja e Gabimeve

**Kategoria:** Fizikë  
**Objektivi:**  Përcaktimi i dendësisë nga matjet e masës dhe vëllimit. Kuptimi i mënyrës si gabimet përhapen në madhësitë e llogaritura.



### Java 7 — Koha e Reagimit dhe Kufizimet e Matjes Njerëzore

**Kategoria:** Fizikë / Sensorë  
**Objektivi:**  Matja e kohës së reagimit me eksperimente të thjeshta. Analiza e variacionit dhe diskutimi i kufizimeve të matjeve manuale.



### Java 8 — Eksperiment Kompjuterik: Koha e Ekzekutimit të Algoritmeve

**Kategoria:** Kompjuter  
**Objektivi:**  Matja e kohës së ekzekutimit për algoritme të thjeshta (p.sh. cikle, renditje). Studimi i varësisë nga madhësia e të dhënave.



### Java 9 — Variacioni i Performancës së Kompjuterit

**Kategoria:** Kompjuter  
**Objektivi:**  Përsëritja e matjeve të kohës për të analizuar variacionin. Diskutim mbi burimet e ndryshimeve (CPU, memoria, sistemi operativ).



### Java 10 — Matja e Intensitetit të Zërit

**Kategoria:** Sensorë  
**Objektivi:**  Matja e niveleve të zërit në mjedise të ndryshme. Analiza e ndryshimeve në kohë dhe krahasimi i burimeve të ndryshme.



### Java 11 — Intensiteti i Dritës dhe Distanca

**Kategoria:** Sensorë  
**Objektivi:**  Matja e intensitetit të dritës në varësi të distancës. Vëzhgimi i trendit dhe krahasimi me pritshmëritë fizike.



### Java 12 — Hartëzimi i Fushës Magnetike

**Kategoria:** Sensorë  
**Objektivi:**  Matja e fushës magnetike në hapësirë (p.sh. në ambient ose pranë objekteve). Krijimi i hartave dhe vizualizimi i të dhënave.



### Java 13 — Saktësia e GPS dhe Variacioni i Pozicionit

**Kategoria:** Sensorë  
**Objektivi:**  Regjistrimi i pozicionit GPS në kohë. Analiza e saktësisë, devijimit dhe variacionit të matjeve.



### Java 14 — Mini Projekt i Integruar

**Kategoria:** Integrim  
**Objektivi:**  Studentët zgjedhin një sistem (fizik, kompjuterik ose sensorik), kryejnë matje, analizojnë të dhënat dhe paraqesin rezultatet në një notebook të strukturuar.



## Shënime

- Çdo laborator kërkon një **raport në Jupyter Notebook**, i dorëzuar në GitHub.
- Çdo raport duhet të përmbajë:
  - Përshkrimin e eksperimentit
  - Metodën e mbledhjes së të dhënave
  - Kodin dhe analizën
  - Grafikët dhe interpretimin
  - Diskutimin e gabimeve dhe kufizimeve
